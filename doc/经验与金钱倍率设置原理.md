# 经验与金钱倍率配置修改原理

## 配置文件

经验和掉钱倍率保存在服务端动态配置文件：

```text
/opt/xxserver/runtime/xx/shm/TTYGZS/dynamicmb/server_set.txt
```

倍率配置按 ID 分成两组：

| ID 范围 | 配置类型 | 时段     |
| ----- | ---- | ------ |
| 1–24  | 经验倍率 | 24 个时段 |
| 25–48 | 掉钱倍率 | 24 个时段 |

每个 ID 对应一个时段。需要所有时段倍率相同，就把对应 24 行的倍率字段设为同一个值；需要按时段调整，则分别修改对应 ID。

## 修改哪一列

配置行以数字 ID 开头，后面紧跟倍率值。修改时保留 ID，只替换倍率字段；该行其余字段保持不变。结构示意：

```text
1    原经验倍率    该行其他字段
1    新经验倍率    该行其他字段（保留）

25   原掉钱倍率    该行其他字段
25   新掉钱倍率    该行其他字段（保留）
```

例如将所有时段的经验倍率设为 `2.5`，就把 ID 1–24 的倍率字段改为 `2.5`；将所有时段的掉钱倍率设为 `3`，就把 ID 25–48 的倍率字段改为 `3`。

## 文件修改注意事项

- 文件使用 GB18030 编码，修改后应保持原编码和换行格式。
- 修改前备份原文件。
- 确认 ID 1–48 每项各有一行且没有重复，不要增删或重排其他配置项。
- 替换文件时保留原文件的属主和权限。可先写入同目录临时文件，检查完成后再替换正式文件。

## 生效方式

配置文件位于服务端的 `dynamicmb` 目录。文件修改完成后，游戏进程何时采用新值取决于服务端的配置读取方式：如果运行中的进程会重新读取该文件，修改可在读取后生效；如果不会自动重读，则需按服务端的加载机制重载配置或重启服务。
