# 掠夺者之剑遁甲术冷却测试

> 当前汇总请参阅 [签系修改当前配置与验证](签系修改当前配置与验证.md)；本文保留专题和历史测试记录。


2026-11-02 测试服两条线路加载装备效果：玩家装备掠夺者之剑 `60075` 时，遁甲术·顺行 `3062、3065`、遁甲术·增寿 `3063`、遁甲术·锐利 `3064` 在技能成功启动并写入冷却时使用 20 秒。未装备时仍读取原有技能配置；已在生效中的冷却不会由该钩子主动重置。

源码为 `scripts/native/looter_cooldown_test.c`，模块 `refresh-ee1c2550c182594d970d9ae4.so`。在 `CServerCha::ProcessCoolDownOfFirstSkillMethod` 读取技能冷却的调用点按武器和技能 ID 覆盖，原生冷却管理器仍负责设置及通知客户端。无需更换客户端包，服务端进程重启后需要重新加载。

用户反馈三个技能显示冷却均约为 20 秒；1 线诊断记录 3 次命中，最近一次为增寿 `3063`，原配置读取值 120。该计数不记录每次技能 ID，因此不能仅凭这份快照证明顺行的两个 ID 均已实测；实际重新释放条件以游戏内测试为准。
