# 签系一键三召唤测试

> 当前汇总请参阅 [签系修改当前配置与验证](签系修改当前配置与验证.md)；本文保留专题和历史测试记录。


## 效果和范围

装备挂机神剑（物品 ID 60074）时，成功使用一次受支持的签系召唤技能，服务端尝试补齐签兵、签将、签王各 1 个。每种在旧类型和新类型之间合计最多保留 1 个；已有其他种类则不再重复召唤。没有装备该武器时，保持原有召唤逻辑。

这是按武器 ID 识别的测试效果，并非可配置的通用装备词条。其入口独立于该武器已有的最大生命值百分比伤害、吸血和召唤物同步九星逻辑。

## 实现方式

源码：`scripts/native/summon_three_signs_test.c`。在已核对版本的游戏进程中，拦截技能事件 `20014`，先执行原始召唤，确认产生新的召唤物后，再使用同一套服务端召唤事件生成缺少的两种。使用各自的召唤类型、NPC 和资源标识，不改变全局召唤上限，也不需要替换客户端资源包。

原召唤的等级用来选择其他两种的 NPC：选择不高于原召唤等级的最高已有档位；若该类型最低档位仍高于原召唤等级，则使用该类型最低档位。签将最低档位为 25 级，签王最低档位为 56 级，因此低等级技能补出的召唤物可能高于原召唤物。

部分原技能带有已有召唤物时禁止施放的状态限制；本效果没有移除该限制。测试时建议先收回现有签系召唤物，再施放一次。
