## 玩法

- 1 砖 = 100 金 = 10000 银 = 1000000 铜。背包流通金在对话中按砖、金、银、铜显示。
- 下注档位依次为 100 砖、10 砖、1 砖，对应底层金额 `100000000`、`10000000`、`1000000` 铜。
- 服务端掷 1–6 点，1–3 为小、4–6 为大。先扣下注额；猜中返还两倍下注额，猜错不返。
- 一局结算后，脚本以 NPC 身份向附近玩家发送包含玩家名字、下注和结果的消息，同时提供“再来一局”选项。
- 翻牌比大、幸运转盘和规则说明仍是占位页面，不能下注。

## 部署与恢复

2026-11-06 已将服务端主包、动态包、脚本包及场景标记部署到云服务器，并更新配置的客户端 `mb.dpk` 与项目 `data/` 工作包。每次更新前均备份；最近一次下注档位调整的备份后缀为 `.bak.xiaohuang-betbricks-20261106`。服务端包位于 `/opt/xxserver/runtime/xx/shm/TTYGZS/`，客户端路径取自 `gm_config.json` 的 `client_mb_dpk`。

重建时，`build_resources.py` 优先从 `data/*.bak.xiaohuang-20261106` 的初始备份读取，避免在已修改包上重复添加 ID。生成的 `build/` 文件不纳入 Git。恢复线上版本时先停服，使用同一批 `.bak.xiaohuang-betbricks-20261106` 备份恢复主包、动态包、脚本包和客户端包，再启动服务；场景标记在这次档位调整中未修改。
